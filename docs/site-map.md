## Main interactions

- Type into the bookshelf search to filter the book cards.
- Use the top navigation to jump between homepage sections.
- The story's Previous and Next controls move between five pages.
- Alt + W jumps to the story on supported desktop browsers and attached keyboards.
- The math practice has addition, subtraction, multiplication and mixed modes.
- Each reference article has a one-question quiz.
