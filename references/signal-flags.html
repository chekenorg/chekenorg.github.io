Maritime signal flags

Messages between ships. Maritime signal flags are standardized, colorful flags that ships can use to communicate letters, coded messages, and specific meanings.

A visual language

Signal flags let ships exchange information using visible shapes and colors. Individual flags can represent letters, and some have special meanings when displayed alone.

Messages and codes

Crews can raise combinations of flags to spell words or convey standardized signals. The International Code of Signals helps provide shared interpretations across different vessels.

Not the same as lighthouse lights

Flags and lights are both visual communication tools, but they are not interchangeable. A lighthouse can help with navigation, whereas signal flags generally carry messages.

In the Willow Pier story

The story uses a chain of lanterns to communicate along the shore. Real maritime signal flags are another way to pass visible messages, although Willow Pier’s lantern system is invented.
